# 📚 AutoAssess – Automated Answer Evaluation System

## 📖 Overview

AutoAssess is a Python-based application developed to automate the evaluation of descriptive answer sheets. The system compares student answers
with predefined answer keys, calculates evaluation scores, and stores the results in an SQLite database. 
The objective is to reduce manual effort while ensuring a consistent and efficient evaluation process.

---

## ✨ Features

- 📄 Evaluate descriptive answer sheets
- 📝 Process multiple student answer documents
- 📚 Support for different question papers
- 📊 Automatic evaluation and scoring
- 💾 Store evaluation results in SQLite database
- 🖥️ User-friendly graphical interface

---

## 🛠️ Technologies Used

- Python
- SQLite
- Tkinter
- python-docx

- Text Similarity

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/preethasivakumar293/AutoAssess.git
```

### Navigate to the project

```bash
cd AutoAssess
```

### Install dependencies

```bash
pip install python-docx
```

### Run the application

```bash
python withdb.py
```
